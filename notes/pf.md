## Introduction to BSD

Unlike Linux distributions, which share a common kernel, the different flavors of BSD do not share a kernel and maintain their own separate codebases.


Linux is strictly just a kernel. Distributions (like Ubuntu or Fedora) combine that kernel with GNU userland tools, shells, and package managers.

BSD is a complete, unified operating system where the core team maintains both the kernel and the base userland (utilities, compilers, and shells) as a single cohesive project.

## Design philosophy and focus

FreeBSD is designed with a focus on high performance, network throughput, system stability, and ease of use. It aims to be a highly versatile, *general-purpose* operating system.

OpenBSD is developed with a relentless, *fanatically secure* focus on security and code correctness. Its developers actively avoid incorporating superfluous features to prevent exposing potential security weaknesses.
